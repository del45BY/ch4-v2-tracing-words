PUT YOUR PICTURES HERE  (one picture per word)

File name  = the ENGLISH word, lowercase, spaces/hyphens -> underscore, e.g.
    cow.png   chicken.png   ice_cream.png   t_rex.png   police_officer.png
Also accepted: the Indonesian word (sapi.png), .jpg / .jpeg, any capitalisation,
or the exact name you type in sheet 'TraceWords' column Image_File.

Best: square PNG with transparent background, 800-1500 px. Bigger files are shrunk automatically.
The full list of names is written to  PRODUCTS/image_list.csv  every time you run main.py.
cow.png is the ONLY demo picture shipped with the program - replace it with your own.
